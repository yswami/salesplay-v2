# SalesPlay customer demo

Live demo: https://yswami.github.io/salesplay-v2/

A focused seller workflow: find an account, understand the fit, and start a useful conversation.

The sample seller is Aster Automation. All accounts, account records, specialist research samples, and buyer responses are fictional. Public DOE and LAE sources establish the industry and equipment context. This independent concept is not connected to live AI, licensed research, CRM, contact enrichment, or outreach.

## Customer demonstration

1. Review the account shortlist and open Ridgeway.
2. Inspect the three facts and optional research connection.
3. Prepare, edit, review, and save a conversation play.
4. Apply “Core assembly is outsourced.” Observe the account exclusion and saved-play review requirement.
5. Open “Try with your accounts” and scope a proposed five-account pilot. The worksheet is local; no service is activated and no list is sent.

The customer-demo guide is available in the About panel. The original v2 product case remains at its previous public PDF URL for existing readers. Original implementation is preserved in Git history; the full earlier package remains in the local workspace.

## Implementation

Plain HTML, CSS, and JavaScript. No build process, backend, analytics, or external runtime dependencies. Browser persistence uses `salesplay-customer-demo-v1`; old v2 storage is untouched. Query-versioned assets prevent stale browser scripts after updates. GitHub Pages serves main at the root.

Icons: official Phosphor SVGs, MIT license in assets/LICENSE-phosphor.txt. Brand mark reused from the original concept.

# SalesPlay v2

[Open the interactive prototype](https://yswami.github.io/salesplay-v2/)

An independent product concept by Yogendra Swami: discover a customer’s growth opportunity, build an editable capacity case, and change the next step when buyer evidence changes.

## Explore

Open Ridgeway’s opportunity, review the evidence, and build the capacity case. Under Validate, apply the sample testing correction to see the modeled output benefit become zero and a saved brief require review.

The static site is published from the root of the `main` branch. There is no build step. Open `index.html` locally to use it offline.

## Sources and sample data

All sellers, accounts, research samples, buyer updates, and economics are fictional. Public sources establish industry context only. No live AI, proprietary dataset, CRM, or outreach service is connected. Changes are stored in the browser. See Product thinking and the included product case for sources and assumptions.
